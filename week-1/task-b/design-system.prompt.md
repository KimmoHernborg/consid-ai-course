# Design System for Private Projects

Prompt to Claude Design:

```
I want to create a design system for use in my personal projects. I want to have a consequent style in all projects I create and that's why I want to build a design system. I would like to use a warm (beige) grey scale as the base colors with a moss green as the highlight / accent color. I would like to use a serif for display texts, but use a sans serif for normal headlines and for normal text. I want to be able to support both light and dark mode.
```

Follow-up:

```
Change the display font to: Fraunces, also make the H1 tags bigger and the text spacing even tighter. Make all the other headlines a bit larger (about 20% larger).
```
